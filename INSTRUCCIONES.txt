1. Descarga y descomprime toda la carpeta. El modo rápido evita los modelos; puede necesitar internet para preparar Python o las zonas horarias. El completo requiere internet y espacio para los modelos.
2. Rápido: iniciar_rapido.cmd en Windows o sh iniciar_rapido.sh en macOS/Linux, sin fallback LLM. Completo: iniciar.cmd o sh iniciar.sh; Windows puede pedir autorización para Microsoft Visual C++.
3. Espera el navegador o abre la URL impresa. Mantén la terminal abierta; Ctrl+C detiene el chat. Si el modo rápido no resuelve una consulta, pedirá aclaración o se abstendrá.
